##  Guide for Adding Future Solutions

Follow these simple steps when adding a new solution:

1. **Identify the Pattern**: Choose the directory that reflects the actual algorithm (e.g. `Two-Pointers-and-Sliding-Window/` or `Graphs/`).
2. **Name the File**: Use standard LeetCode conventions:
   ```
   <ProblemNumber>_<PascalCaseTitle>.<ext>
   # Example: 15_3Sum.py or 200_NumberOfIslands.cpp
   ```
3. **Include Header Metadata (Optional)**:
   ```python
   """
   Problem #15: 3Sum
   Difficulty: Medium
   Pattern: Two Pointers
   Time Complexity: O(N^2)
   Space Complexity: O(1) auxiliary
   """
   ```
4. **Update Repository Index**:
   ```bash
   python scripts/repo_tool.py all
   ```
   This automatically updates `PROBLEM_INDEX.md`, refreshes the README statistics, and validates syntax and links.
